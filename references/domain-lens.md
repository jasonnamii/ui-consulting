# 도메인 렌즈 (Domain Lens)

ux-advisor의 도메인별 특수 고려사항. 질문 파싱 시 도메인 감지→해당 렌즈 적용.

---

## 도메인별 렌즈

### 모바일 앱
- **제약**: 화면 작음, 한 손 사용, 배터리, 오프라인
- **특화 원리**: Thumb Zone, Touch Target 44pt, Doherty Threshold
- **트렌드**: 제스처 네비, Bottom Sheet, 다크모드
- **실패 지뢰**: 데스크톱 UI 이식, 팝업 남발, 긴 폼

### 웹 SaaS
- **제약**: 다양한 해상도, 키보드 사용자, 파워유저
- **특화 원리**: 키보드 단축키, Progressive Disclosure, Information Density
- **트렌드**: Cmd+K Command Palette, 실시간 협업, 다크모드
- **실패 지뢰**: 모바일 우선에 파워유저 소외, 과도한 온보딩

### 이커머스
- **제약**: 신뢰 확보, 결제 전환율
- **특화 원리**: Loss Aversion(재고), Social Proof(리뷰), Scarcity, Default(배송옵션)
- **트렌드**: 원탭 결제, 라이브커머스, 개인화 추천
- **실패 지뢰**: 숨은 비용(배송비), 회원가입 강제, 과도한 업셀

### 핀테크
- **제약**: 규제·신뢰·보안
- **특화 원리**: Error Prevention, Reversibility(취소 30일), 생체인증
- **트렌드**: 미니멀 대시보드, 실시간 알림, 자동분류
- **실패 지뢰**: 복잡한 인증, 금액 오류, 지연된 반영

### 헬스·피트니스
- **제약**: 습관 형성, 장기 사용
- **특화 원리**: Goal Gradient, Streak, Peak-End, Hooked Model
- **트렌드**: 게이미피케이션, 웨어러블 연동, 커뮤니티
- **실패 지뢰**: 죄책감 유도, 개인정보 과수집

### 교육
- **제약**: 이탈률 높음, 학습곡선
- **특화 원리**: Spaced Repetition, Goal Gradient, Variable Reward
- **트렌드**: 마이크로러닝, 인터랙티브, AI 튜터
- **실패 지뢰**: 영상만 나열, 완강률 무관심

### 소셜·콘텐츠
- **제약**: 네트워크 효과 필요, 중독성 윤리
- **특화 원리**: Social Proof, Variable Reward, FOMO, Reciprocity
- **트렌드**: 알고리즘 피드, 숏폼, 실시간 상호작용
- **실패 지뢰**: 악성 사용자 방치, 다크패턴 중독

### AI 프로덕트
- **제약**: 불확실성 응답, 환각, 지연
- **특화 원리**: System Status(스트리밍), Error Recovery(재생성), Progressive Disclosure
- **트렌드**: 대화 UI, 인용·출처, 에이전트 행동
- **실패 지뢰**: 환각 방치, 지나친 자신감 표현, 컨텍스트 유실

### B2B 엔터프라이즈
- **제약**: 관리자·사용자 분리, 권한·감사, 기존 시스템 연동
- **특화 원리**: Flexibility(초/중/고급), Consistency across tools
- **트렌드**: API First, 통합, 키보드 드리븐
- **실패 지뢰**: 관리자 전용 기능 과다, 온보딩 없음

### 게임
- **제약**: 재미 우선, 진입장벽 vs 깊이
- **특화 원리**: Variable Reward, Goal Gradient, Peak-End, Flow
- **트렌드**: F2P 과금 설계, 크로스플랫폼
- **실패 지뢰**: P2W(Pay to Win) 반감

## 타겟 사용자 렌즈

### 노년층 (65+)
- 큰 글자·버튼, 낮은 대비 주의, 제스처 최소
- 🟦~🟩 권장, 🟥 지양

### Gen Z (1997~2012)
- 숏폼·세로·제스처 선호, 텍스트 적게
- 🟨~🟥 선호

### 파워유저·전문가
- 키보드 단축키, 정보 밀도, 커스터마이즈
- 🟨~🟥 선호

### 초보·일반 대중
- Jakob's Law 철저, 학습비용 최소
- 🟩 기본값

### 아동 (6~13)
- 큰 터치 영역, 색·소리 풍부, 텍스트 최소
- 🟩~🟨 + 안전 필터
